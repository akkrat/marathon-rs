# Test root factory probes (WP 4.5b)

`python3 tools/oracle/test-root-probes/run.py [output/probes.jsonl]` compiles the
unchanged e47352f2 TestRootFactory, AppleDevice, RemoteFileManager,
DistributedDerivedData, binary wrappers and model sources against the installed
read-only Kotlin distribution jars. The compiler jars come from the Gradle
cache (Kotlin 1.9.24); the default JDK is Android Studio's JBR 21.0.10.
Everything compiled/extracted is in a temporary directory. No source checkout
or real worker is written; no Xcode, SSH, signing or credential is involved.

The default destination is `fixtures/oracle/test-root/`. `probes.jsonl` holds
factory inputs, exact base64 XML bytes, command argv/timeouts, shared/generated
pushes, their combined chronological order, exception class/message/reason,
and whether staged files were deleted. Only host bundle paths in errors are
normalized to `<bundle>`. Worker paths and XML are never normalized. The input
records describe synthetic bundle construction in run.py; `real=true` extracts
unchanged `fixtures/bundles/{ios,macos}.zip` into scratch directories.

`staging-edges.jsonl` records a deterministic write denial and the two approved
P2 surrogate inputs. The JDK 21 SecurityManager probe denies only the writer's
second write access to the new xctestrun, after successful temp allocation; the
real factory must delete that file in finally. The Rust staging unit test
injects that observed error at its writer seam. This avoids a filesystem race.
The JDK's SecurityManager deprecation warnings are expected. Surrogates also
fail in Kotlin, at the writer; P2 deliberately reports the offending config
field earlier. The input identifies the field rather than embedding an invalid
surrogate in JSON. The `noApp` witness clears the already-constructed bundle's
application field solely to reach the factory's defensive branch (normal
AppleTestBundle construction rejects absent applications first, A27).

The recording device is a Java dynamic proxy; suspend exceptions are delivered
through continuations, avoiding Java proxy wrapping of checked IOExceptions.
Default transfer recording observes bytes while the temp file still exists.
The four simulator integration rows are tested in Rust against the production
transfer helper and FakeSimulatorWorker; provider/boot integration remains 5.2.
The fake supplies recorded command responses; it does not run Apple binaries.

`temp-prefixes.jsonl` adds the actual factory's slash-containing UDID witness:
NIO temp allocation rejects it with IllegalArgumentException after the preceding
factory commands/transfers and before any generated-file push. Unlike the JDK,
tempfile 3.27.0 explicitly permits separators in prefixes, so the Rust adapter
rejects them before native allocation. This is documented library behavior,
not an upstream bug. All 183 scenarios are generated by the same command.
