# Bugs found along the way, outside the Kotlin marathon

`docs/known-kotlin-bugs.md` lists the Kotlin marathon's own bugs, most of which marathon-rs keeps. This file collects everything else we trip over while porting: bugs in third-party libraries, the JDK, tools, the fork's build and CI, or in our own harnesses after a fix. It is a backlog for upstream reports and later clean-up, not a promise that each row is fixed.

**How to maintain this list**
- Implementers and reviewers record such a bug in their WP's results or findings doc, under a heading "Incidental bugs". The orchestrator copies each one here when the WP merges.
- Each entry gives: where (crate or tool and version, file:line if known), the behaviour, how it was seen (WP, test or command), what we do about it (workaround, patch, deviation, nothing), and whether it was reported upstream.

Status values: `open`, `worked-around`, `patched-locally`, `reported`, `fixed-upstream`, `fixed` (fixed in this repository, in the product or in a harness), `moot` (the code it concerned is gone or unused) and `withdrawn`.
