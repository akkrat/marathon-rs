| `d2` | `[DecodedString(value=<first original element>), ...]` | 7 |

The angle-bracket payload notation and ellipsis summarize long strings; they
are not literal output. Independently reconstructed **all 28 complete strings**
from the unchanged structured metadata in the same view's per-test result JSON:
integer `value` fields become `DecodedInt(value=N)`, string `value` fields become
`DecodedString(value=S)`, preserving every payload character and element order.
Every reconstructed string equals its new raw value. This checks the long `d1`
control/Unicode payloads and every `d2` element, rather than accepting a prefix
or a broad identity regex as proof.

No decoded-null or version/log identity witness is present in these native
views; focused tests cover those changes. `cargo test -p marathon-cli --test
config_contract` passed both tests without blessing, so the configuration corpus
is unchanged. Copied oracle fixtures and replay tapes are untouched.
