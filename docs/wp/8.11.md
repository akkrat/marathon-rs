# WP 8.11: Native rendering instead of Kotlin `toString`

Effort **L–M** (decided at the design stop). Branch `wp/8.11-kotlin-rendering`, based on `main` after WP
8.9 (commit `64f286ee`). WP 8.10 runs in parallel; whichever merges second rebases.

## Why

`jcompat::writers::KotlinValue` (`crates/jcompat/src/writers/kotlin.rs`) renders values the way Kotlin's
generated `toString` does: `Name(field=value, …)`, `[a, b]`, `{k=v}`. About 190 uses in 14 files:
configuration rendering (`marathon-config/src/render.rs`, which feeds Allure `environment.xml` and log
lines), annotation metadata (`marathon-core/src/filter/annotation.rs`, `model.rs`,
`report/projection.rs`), analytics (`analytics/provider.rs`), and vendor log or message text (Android
runner, ADB instrumentation, iOS timing and provider formatting, Apple runner, events, connection
factory).

## Scope: decide per use, at the design stop

Classify every use into one of three groups and propose the treatment:

1. **Input meaning (keep exactly).** Text that user input is matched against is input syntax (PLAN.md
   §3.12 point 1). In particular the `annotationData` filter matches its `valueRegex` against the rendered
   annotation value (see D58). Changing that text changes which tests a user's filter selects. Keep it
   byte-identical; move the renderer next to its user (for example a documented `annotation_text`
   function in `marathon-core`), with a doc comment stating the format as part of the filter's contract.
2. **Result files (change only with a D-row).** Allure `environment.xml` values, and anything else that
   reaches a result file or a request sent to an analytics backend (check `provider.rs`: if the text is a
   query or a key the backend stores, it is data and stays). Propose whether to keep or switch to a plain
   rendering (for example serde JSON for nested values); a switch needs D62 and a reviewed golden update.
3. **Logs and messages (free to change).** Use `Display`/`Debug` impls or format strings directly.

Then delete `KotlinValue` and `writers` from `jcompat` if nothing is left there.

**Out of scope:** any other output; config parsing.
