## Inherited residuals and comparison decisions

Standalone parse validation requires its JVM driver transcript; malformed `{}`
transcripts return `Invalid`; every contract requires a scenario adapter and
terminal observations; component globs keep `*` within one path segment and use
explicit `**` for recursion. Fully shaped provenance remains descriptive, with
reviewed registry hashes as the origin guard. Factory fingerprints now exclude
unrelated CLI functions. Allure modes deliberately use the canonical harness
root `reports/allure-results/` for every vendor, independent of physical output
paths; other roots cannot opt into those structural modes accidentally.

Typed JSON rewriting preserves similarly named user metadata and UUID literals.
D12/F29 object substitution validates JVM taped IDs and native class-name hashes.
Transport projections retain control-connection distinctions and ordered lanes;
rsync-generated server protocol options/traffic are diagnostics for the supported
openrsync/Samba substitutes, while caller flags, remote paths, statuses and
transferred/consumed bytes remain contracts. Stdout/stderr are separate and
otherwise ordered. Explicit concurrent stdout blocks are the adjacent artifact admission/worker
queue-wait pair and the caller provider-initialized timing line versus the
independent iOS update-consumer two-line event: both full lines/values/multiplicity
remain, with either source-observed order accepted. This is a narrow causal
projection, not a new production deviation or a general log sort.

P1 consumes the existing owners' installer, recovery/fault, Android artifact,
coverage and runner contracts rather than adding a whole-CLI feature cross-product.
P3's approved actual-local pair plus labelled Apple world suite remains the local
coverage. Whole real local/SSH/device certification is 7.2. There is no new
intentional production difference and no request for an additional D-number.
