## Goal

Provide byte-exact number/time text for configuration binding, reports, analytics queries and logs. Reuse the validated WP 0.3b YAML spike number and time implementations, credit their origin, and retain checked arithmetic.

## Deliverables

- `jnum`: Java Double parsing/printing, Float printing, Character.digit, checked integer and Decimal parsing.
- `jtime`: normalized Instant/Duration constructors, ISO parsing and display.
- `formatting`: the three UTC date patterns, en-US default and locale-explicit fixed decimal and percent formats, and the StdoutReporter duration pattern/wrapper.
- Oracle-driven integration tests; findings with limitations and incidental bugs.

## Round-1 contract update (D8)

Default-locale output is always en-US, independent of environment or machine locale:
WP 3.9c uses `format_date` for the HTML footer, WP 3.5 uses `format_percent`
for progress, and WP 0.6 uses `format_fixed` for file-transfer messages.
The `_with_locale` APIs retain the four oracle locales for explicit callers;
JUnit pins US, while Graphite is locale-independent. UTC remains pinned.
`format_graphite(Instant)` covers DateTimeFormatter's full UTC LocalDate range
and returns None for Instants outside it. Instant and Duration fields are private;
checked constructors and `seconds()`/`nanos()` accessors preserve normalization.

`formatting_round1.jsonl` adds 2,093 generated reference-JBR rows: 76 Graphite
boundary witnesses, 1,860 code-point digit rows, 97 BigDecimal rows and 60
checked time-constructor rows. Total coverage: 17,399 rows.
