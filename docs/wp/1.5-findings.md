# WP 1.5 findings

## Result and API

`jcompat::writers` exposes `JavaString(Vec<u16>)`, ordered `WriterValue`, validated
`JavaNumber` spellings, `GsonWriter { pretty }`, `JacksonYamlWriter`, and
`KotlinValue::render`. Writers return Java strings; `as_utf8()` is fallible and
`to_utf8_bytes()` reproduces the JVM encoder's replacement (`?`) at file output.

`JavaNumber::new` accepts Java-format numeric text; WP 1.2 owns float/double
conversion. Models must supply declaration-order fields, insertion-order maps,
File.absolutePath strings and explicit custom toString overrides. The generic
writer does not inspect Rust structs or apply model-specific exclusions. D3's
omission of the lazy serial delegate belongs to the report model projection;
the historical Gson fixture still checks the raw library's ability to write it.

- All 15 original Gson rows pass, including non-finite rejection and the lone

- All 6 P3 YAML rows pass, including metadata order and long-line wrapping.
- C60a–c pass in the spike corpus runner (`emit: 3/3`, zero divergences).

  wrapping, controls, lone surrogates, finite/non-finite numeric spellings,
