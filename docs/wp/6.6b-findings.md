## Implementation and decisions

All five artifact listeners are installed by `ListenerSlots::default()`: file
sync, video, screenshot GIF, adam capture, profiling. The composite and provider
orders remain recorder/log/results/debug/adam/filesync/profiling and
recorder/profiling/log/adam respectively. Profiling requires enabled + pbtxt;
recorder selection reuses 6.5. File sync reads the provider's effective pull set
at before/after callbacks, including Allure and coverage. No core trait was widened.

P1/P3/P5 are implemented: process-kill delays use VendorClock, completed-join GIF
deletion is direct (the JVM handler fires immediately on the caller thread), and
recorder state is synchronized in short critical sections. P4 stops/joins
profiling after run failure without pulling or deleting the remote trace. P2
was rejected and is not implemented: unreadable config, missing bundle and empty
batch still fail the batch. PLAN D16 records the approved changes; D14/D15 remain
inherited from the stacked parents.

The batch executor now retains a spawned owner and a result channel. Closing its
waiter signals cancellation to the runner; final cleanup runs with a protected
signal, after the runner's instrumentation cleanup, and joins artifact children.
Video/GIF cleanup cancels and joins without adding remote shell commands.
Profiling inherits execute cancellation and its final cleanup can stop an active
perfetto job. Detached Kotlin supervisor state is not intentionally leaked.
The discarded screenshot/video Deferred failures remain unobserved on normal
callbacks, matching Kotlin; profiling join also does not rethrow child failures.

## Incidental bugs

**U79 — provider collision test races logcat startup (fixed).**
`same_serial_on_two_servers_collides` received both Connected events and then
immediately disconnected a server. Setup spawns logcat before emitting Connected,
but does not await its transport handshake. Disconnect/termination could reset
that handshake, producing a fake-server warning and failing the zero-warning
assertion. Reproduced locally on repetition 2; a diagnostic rerun captured
`connection 11: Connection reset by peer` after transport selection and before
the logcat shell request. The test now waits, with a bounded timeout, for both
fake servers to record the logcat shell command before disconnecting. All
collision, identity, health, borrow, and zero-warning assertions remain intact.
U78 remains unused.
