# WP 8.18 test changes (D64)

## Item 1: ordinary cancellation

- `marathon-core/tests/queue_prepare.rs::cancelling_a_prepare_waiter_keeps_the_other_pools_single_flight_fetch`:
  construct Requested instead of Parent; retain the exact cancellation payload,
  independent in-flight fetch, cache and timing-log assertions.
- `marathon-core/tests/runtime_races.rs::timeout_panics_surface_as_failures_without_leaving_children_live`:
  expect Requested instead of Parent for the failed body's descendant cancellation;
  retain the failure payload, cleanup timing, parent isolation and quiescence assertions.

These are synthetic Rust tests, not mapped Kotlin test methods. No parity rows
are retired. Copied fixtures, native goldens and the configuration corpus stay
unchanged.

## Item 2: non-disposable completion callbacks

- `marathon-core/tests/runtime_behavior.rs::completion_callbacks_are_once_late_and_disposable`
  becomes `completion_callbacks_are_once_and_late_d64`: register both callbacks
  without a disposal handle, assert synchronous completion in order `1,2`, then
  retain repeated complete/cancel and immediate late-registration checks with
  final order `1,2,3`.
- `marathon-core/tests/runtime_oracle.rs::structured_coroutines_corpus_matches_runtime`:
  remove disposal of callback 2. Assert the immutable JVM `job:callback-order`
  row remains `1,3` and the native result is `1,2,3` under D64. Compare every
  other timeout, delay and failure row unchanged.
- Compile-only contract `marathon-core/tests/contracts.rs::ContextHandler`:
  remove the stored completion handle and register directly, retaining the
  weak actor capture and completion-time close callback. No assertions change.

No other test body or expectation changes. Existing deep-chain, many-callback,
parent-continuation, actor-retention, already-cancelled construction, timeout
cleanup and DeviceActor accounting/termination witnesses remain unchanged.
The retired disposal comparison is a synthetic Rust probe, with no mapped
Kotlin test row to mark `n/a`.
