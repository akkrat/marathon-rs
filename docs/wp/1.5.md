## Goal

Byte-exact Gson report output, Jackson/SnakeYAML P3 output and Kotlin data-class
string construction. Preserve Java UTF-16 strings, declaration/insertion order,
null omission and the distinction between integer and floating-point spellings.
Domain serializers remain with their owning WPs; this package supplies the writer.

## Deliverables and acceptance

- Ordered writer values, lossless Java strings, Gson compact/pretty formatting,
  HTML escaping and non-finite number rejection.
- Jackson YAML document marker, NON_NULL, quoted values, YAML-safe keys,
  indentless sequences and SnakeYAML double-quoted escaping/wrapping.
- Kotlin data-class, collection, map and tuple formatting, without string escaping.
- Oracle-driven tests for the existing tables and three skipped YAML emitter rows;
  additional JVM-generated edge cases where the existing tables lack inputs.
- `scripts/check.sh` passes. No parity-matrix or source-inventory rows are assigned
  to 1.5; the consuming model modules remain with their existing owners.

Paths below are relative to the Kotlin repository (package roots omitted after
`src/main/kotlin/com/malinskiy/marathon/`).

  `core/.../json/FileSerializer.kt`: absolute File path projection.

  `report/bill/BillingReporter.kt`, `report/raw/RawJsonReporter.kt`,

- `vendor/vendor-apple/ios/.../apple/ios/IosVendor.kt` and
