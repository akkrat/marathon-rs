# WP 8.8 test changes

## Review round

New tests: `marathon-cli/tests/signal_windows.rs::a_slow_exit_preparation_still_exits_with_the_signal_status`
(the exit-hook race, P1); `marathon-cli/tests/tracing_output.rs::queued_records_render_raw_traces_at_their_own_time`
(raw core/vendor stack traces and per-record stamps) and the `closed` child
mode of `cancellation_flushes_even_when_process_exit_skips_guards`
(`exit_after_flush` after the writer closed);
`marathon-logging::known_hosts_warns_in_every_configurator_with_debug_off`;
`tools/differential/test_evidence.py::test_native_golden_console_comparison_end_to_end`
(mutated golden through the production native comparator). Changed:
`a_second_signal_exits_at_once_during_a_blocked_sink` now holds the first
signal's watchdog open through a seam instead of racing the 1 s deadline.
`signal_windows.rs`, `tracing_output.rs`, `run_outcome.rs`,
`production_runner.rs` and the differential probe pass a stamp closure
(`Option<wall_millis> -> String`) instead of a millis clock.

Milestone 1 (the pilot) changed only `crates/marathon-cli/tests/cli_matrix.rs`
and `production_runner.rs`, normalising the startup timestamp instead of the
old diagnostic prefix; those changes are included below.

Classification used here:

- **Mechanical:** only logging type paths or signatures changed (`Logger` →
  `Component`, `jcompat::logging::Level` → `marathon_logging::Level`,
  registry `logger(name, level)` → `component(name)`), observer callbacks
  splitting happened/should-log (level rendering moved to the observer),
  clippy `must_use`/synthetic `Drop` follow-ups, and import/assert formatting
  needed to compile the same assertions. No product behaviour in the test
  changed.
- **Changed assertion:** the test now pins WP 8.8's permitted native wording,
  logger targets, filter semantics, or test-owned level pins, where a Kotlin
  logger name or level rule was previously recorded.
- **Deleted:** the test asserted a removed emulation mechanism (layout,
  abbreviation, Jansi stream state, mutable registered levels) and no native
  equivalent exists to assert.
- **New:** added by WP 8.8.

Every oracle remains in use. Expected logger names recorded by the JVM are
translated to Rust targets by `marathon_test_support::recorded_logs`
(`native_logs` / `target`), applied only to oracle log trees. No oracle,
scenario tape, or copied fixture changed. Real-time tests follow
`docs/testing.md`: virtual time in-process; the signal/console deadline tests
use bounded waits on observable sink state with wall time on the last hop.
