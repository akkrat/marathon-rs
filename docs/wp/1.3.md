## Goal

Reproduce the default commons-text `StringSubstitutor` used by marathon, with an injectable string lookup for controlled environment substitution and profiling maps.

## Deliverables

- `jcompat::StringSubstitutor` and a cycle error carrying the Java exception class and exact message.
- Oracle-driven tests for escapes, defaults, nesting, recursive values, undefined and empty variables, cycles, and prefix/suffix edge cases.
- Findings and verification results in `docs/wp/1.3-findings.md`.

## Kotlin call sites

All paths are relative to the Kotlin repository:
- `configuration/src/main/kotlin/com/malinskiy/marathon/config/serialization/ConfigurationFactory.kt`: `parse`, substitutes the entire Marathonfile before parsing.
- `vendor/vendor-apple/ios/src/main/kotlin/com/malinskiy/marathon/apple/ios/device/AppleSimulatorProvider.kt`: static Marathondevices and dynamic update messages.
- `vendor/vendor-apple/macos/src/main/kotlin/com/malinskiy/marathon/apple/macos/AppleMacosProvider.kt`: static Marathondevices.
- `vendor/vendor-android/src/main/kotlin/com/malinskiy/marathon/android/executor/listeners/profiling/ProfilingRunListener.kt`: tracing config, using `TRACING_TARGET_PID` and `TRACING_TARGET_PACKAGE`. Callers convert non-null map values to strings; a null PID is undefined.
