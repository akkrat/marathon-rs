## Behaviours to reproduce

Line numbers are `B/AppleApplicationInstaller.kt` unless prefixed.

- **Config reads and failure order (:25–32):** `xctestrunEnv` null → `IllegalArgumentException("No xctestrunEnv provided")`, then xcresult (`"No xcresult configuration provided"`), then bundle/xctest (`"No test bundle provided"`), all before any worker command. `AppleTestBundle(app, testApp, xctest, sdk)` uses the **resolved** `app`/`testApp`; its eager `appId` throws `ConfigurationException("No bundle identifier specified in null")` when `app` is null, A27 when the key is missing — so every app-less configuration fails here.
- **Flag on (:37–39, `DistributedDerivedData.kt:28–45`):** debug `Skip moving xctest to <serial>`; **no** mkdir, retry or push. Without test application: check `<shared>/marathon.xctest/<rel…>/<testBinary name>`. With one: remote xctest = runner app joined with the local `relativePathTo` segments; check the runner binary **then** the test binary inside it, both naming `testApplication` as the local source. macOS's `skipCopyingDerivedData()` is always false (`B/extensions/ConfigurationExtensions.kt:50–61`), so this branch is iOS-only.
- **Test application (:40–51):** debug `Moving xctest runner application to <serial>`; remote xctest as above, split on `File.separator` (`/`). `withRetry(3, 1000)`: each attempt runs `create_remote_directory()`, `create_remote_shared_directory()`, then `push_shared(testApp, remoteTestRunnerApplication)`; false → `DeviceSetupException("Error transferring <xctest> to <serial>")` — the message names the **xctest**, not the app pushed (new bug row). `Retry.kt:8–24`: cancellation propagates immediately, any other error (including the DeviceSetup above) is retried after 1000 ms on the vendor clock, the last one propagates; mkdir failures never reach it (A43/A44).
- **Plain xctest (:52–62):** debug `Moving xctest to <serial>`; same retry shape pushing the xctest to `remote_xctest_file()`.
- **Test root (:64–69):** debug `Generating test root for <serial>`; remote test binary = remote xctest + relative binary path + local test binary name. `getTestTypeFor` (:85–110), then `TestRootFactory(device, env, xcresult, flag).generate(type, bundle, use_xctest_parser)`, then `after_install`. Factory errors propagate unchanged.
- **Test type (:85–127):** configured `testType` wins, else `nm.list(remoteTestBinary, ["KIFTestCase", "XCUIApplication"])` in that order (LinkedHashSet) → XCUITEST iff some line contains `XCUIApplication` and none contains `KIFTestCase`, else XCTEST. Overrides read the **raw** `application` field, not the resolved `app`: LOGIC_TEST on IPHONEOS with app → warn and XCTEST; without → `ConfigurationException("Logic tests should target only iPhone Simulator")`; XCTEST on IPHONESIMULATOR without → warn and LOGIC_TEST (then 4.5b's `TODO()`); any other non-logic type without → `"Application is required for test type <TYPE>"` (enum name). Consequence to reproduce: a `derivedDataDir` configuration whose `app` was found still fails (XCUITEST) or becomes a logic test (XCTEST) — new bug row, oracle-confirmed. Warn texts exact, including "Logic Test".
- **Extra applications (:71–80):** after `after_install`, in list order: a directory with extension exactly `app` (`File.extension`, text after the last dot of the name) → debug `Installing extra application <path> to <serial>`, `push_shared(it, remote_extra_application(name))`, `install(remote)`; **both Booleans ignored**, no retry. Anything else → warn `Extra application <path> should be a directory with extension app`. Paths render as `File.toString()` (jcompat `JavaPath`).
- **Logging:** logger named after the Kotlin class through 1.x/jcompat logging; levels and texts above exact.

**Known bugs that apply:** A9 (row 16's second xctest push), A27, A37 (shared reuse per source path; rows 14–16 send to different destinations), A43/A44 (mkdir inside the retry is swallowed), A45 (lipo selection inside the factory). New rows (next free A-numbers at implementation): installer error message naming the xctest; raw-`application` test-type check versus resolved `app`; extra-application push/install results ignored.
