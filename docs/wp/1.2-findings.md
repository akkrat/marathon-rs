## API and scope

- `jnum`: `double_to_string`, `float_to_string`, `parse_double`, `digit`,
  `is_digit`, `parse_radix`, `parse_long`, `Decimal::{parse,scale,extract_seconds_and_nanos}`.
- `jtime`: `Instant`, `Duration`, normalized `instant_of`/`duration_of`,
  `parse_instant`/`parse_duration`, Java Display, Instant boundary constants.
  Fields are private; construct valid values through normalized constructors
  and read them with `seconds()` and `nanos()`.
- `formatting`: `format_fixed` (precision 2 or 4), `format_percent`,
  `format_duration`, `format_stdout_duration`, `format_date`, `DatePattern`,
  `Locale` and `Locale::from_language_tag`; `_with_locale` variants preserve
  explicit-locale formatting, and `format_graphite(Instant)` preserves its full range.

Formatting implements exactly the three source date patterns and three
String.format patterns. Dates use UTC and distinguish SimpleDateFormat's
Julian/Gregorian cutover from DateTimeFormatter's proleptic Gregorian calendar.
Default-locale output uses en-US under D8 without reading environment locale.
WP 3.9c's HTML footer, WP 3.5's progress text, and WP 0.6's file-transfer
messages use the default APIs. Explicit-locale variants cover ROOT, US,
German and Russian; unrecognized explicit tags return None. JUnit pins US;
Graphite is locale-independent. UTC remains pinned at all date call sites.
The month-name tables freeze JBR 21's CLDR data.
No open implementation questions remain.

C15's locale-dependent footer is superseded by D8; its pool-path portion
remains pending.
The inherited Jackson DecimalUtils negative-fraction sign quirk is retained
in `Decimal::extract_seconds_and_nanos`; it is a library behaviour rather
than a newly discovered Kotlin marathon bug.
