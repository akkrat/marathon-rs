Establish roles from explicit scenario identities/taped choices, not “whichever device passed first.” Map only designated nondeterministic fields; keep test names, literal user strings, status, numeric formatting and array order. Taped clocks/durations/IDs compare exactly. In live runs mask only documented volatile fields; retain raw values and validate time relationships. Never globally regex-replace UUID/time-like text, sort every array or reserialize Gson/JUnit/HTML to conceal byte differences. Use parsed locations/token spans to rewrite designated text while preserving surrounding bytes; reject unknown formats or unclassified differences.
- **Approved exceptions:** D1's telemetry line, D3 field omission, D6 regex rejection, D8 locale, D9 load-stage changes, D10/D11 decoding, D12 runtime text/signals and D13 query timing get narrow case/field expectations with both JVM and Rust evidence.
