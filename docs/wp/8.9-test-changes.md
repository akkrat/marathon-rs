## Test infrastructure and executable checks

`marathon-test-support::yaml` invokes the gate's existing
`tools/differential/evidence.py::structured_yaml` reader in a separate process.
That reader uses the already-built `snakeyaml` YAML-tree helper, independently of
configuration binding; it shares the underlying parser with the loader. No new
external tool or parser dependency is added. It preserves ordered keys, distinguishes
scalar types and compares exact decimal data. Property expectations come from
source values, not reserialized output. The loader assertions separately check full
Configuration equality or the typed token stream of parse-result-shaped data.

`crates/marathon-config/examples/corpus.rs::run`'s emit checks and `emit_case` now
serialize borrowed serde views of the oracle projection and compare YAML data.
The example still runs all recorded token and binding cases.
`crates/marathon-core/tests/contracts.rs::writer_contract` now accepts typed serde
YAML models and propagates serialization errors; it remains a compile-only contract.
