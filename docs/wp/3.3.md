## Behaviours to reproduce

- **Single-value state** (`F/SingleValueTestFilter.kt:17–35`): explicit `values`, including an empty list, wins over the lazy file cache. Read at the first predicate evaluation; disabled or empty input never initializes it. A successful missing-file result is cached; a thrown Kotlin lazy initializer is retried next time. Filter and filterNot share the cache. Ordinary disabled filters return the original sequence for both operations. Enabled leaf operations preserve order, duplicates and original metadata. Do not implement filterNot as set subtraction except where composition explicitly does so.
- **Name predicates:** simple class uses `clazz` (`SimpleClassnameFilter.kt:10–12`); simple test is `clazz#method` (`SimpleTestnameFilter.kt:12–14`), method uses raw `method` (`TestMethodFilter.kt:10–11`), FQ class uses `toClassName('.')` (`FullyQualifiedClassnameFilter.kt:12–13`), FQ test uses `toTestName('.', '#')` (`FullyQualifiedTestnameFilter.kt:12–13`). Each combines optional full-match regex and optional exact values with AND, absence meaning true. Reuse merged name helpers; blank packages are omitted (`K/test/Test.kt:25–48`). Package uses exact `pkg` or `value + '.'` prefix when `subpackages=true`, never arbitrary prefix (`TestPackageFilter.kt:11–18`). Regex still applies to the package itself. D9 already drops null values, including its documented `null.` subpackage exception; do not reconstruct them.
- **Annotation names** (`F/AnnotationFilter.kt:11–23`): any name matches; regex takes precedence over values, otherwise non-empty name intersection, otherwise true. Empty/missing file gives an empty values list and matches nothing. Directly constructed invalid configs can differ from validated configs; the factory must not silently add validation or combine the regex/value branches.
- **Values files** (`F/FilterValuesFileReader.kt:9–21`): null path returns null, missing path returns empty and logs ERROR under `FilterValuesFileReader`: `Filtering configuration file <absoluteFile> does not exist. Applying empty list.` Existing unreadable files/directories and read failures throw; do not turn them into empty lists. Kotlin `readLines()` is UTF-8 with replacement, CR/LF/CRLF line handling. First drop Kotlin-blank lines and lines whose Kotlin-trimmed text starts `#`; then remove `\s+#.*$` using Java's built-in ASCII whitespace class and Kotlin-trim the result. `Class#method` and `x#literal` survive, `x #comment` becomes `x`; retain duplicate values/order and BOM behaviour. This built-in pattern is not a user D6 pattern: implement its small fixed semantics without accidentally making `\s` Unicode. Reuse `jstring` whitespace/trim, Java path spelling and UTF-8 primitives; no canonicalization or extra env substitution here.
- **Composition** (`F/CompositionFilter.kt:13–57`): UNION runs every child against the original input and accumulates an insertion-ordered union (child order determines output order). INTERSECTION starts with the input's ordered set and intersects each child's result on the original input, without stopping when the accumulator becomes empty. SUBTRACT with zero **or one** child returns input untouched without invoking any child; with ≥2, run the first on input, then every later child against that **original left result**, subtracting from an ordered set accumulator. Enabled filterNot computes filter once then `tests.subtract(filtered).toList()`, deduplicating the complement. Disabled composition returns input, duplicates intact. Empty UNION selects none; empty INTERSECTION selects the input set. Test equality ignores metadata, so retain the first representative selected by Kotlin's set operations, even when a later equal test has different annotations. Do not use unordered HashSet iteration.
- **Annotation data** (`F/AnnotationDataFilter.kt:10–42`): one and the same metadata entry must full-match both name and value; missing/null `value` is false. An object array renders **each element** with Kotlin toString, then `substringAfter("(value=")` followed by `substringBefore(")")`, first delimiters only, unchanged on absent delimiter, before any-match. Non-arrays render the whole value, including list/map brackets. Preserve typed primitive/boxed formatting, null array elements (`"null"`) and C28's DEX wrappers rather than recursively unboxing them. Use `DecodedWrapper::kotlin_value`, the merged Kotlin writer and the existing replay identity hook for the stable DecodedNull singleton suffix. C19's outer array identity in reports is 3.9b's separate concern.
- **Fragmentation** (`F/FragmentationFilter.kt:20–48`): hash `toTestName('.', '#')` as signed BigInteger MD5, Java remainder by count, adding count once if negative, compare with index. Reuse `signed_md5_utf16` + `fragment_index_for_hash`; no unsigned hash or absolute value. Preserve disabled identity and sequence order. Config checks already live in 2.4 (`FilteringConfiguration.kt:249–252`); direct unvalidated count=0 fails only on evaluating a test, so empty input must not fail eagerly. Return the throw-equivalent error, never panic.
- **Allure wrapper** (`F/AllureTestFilter.kt:12–55`): lazy supplier once per filter on enabled calls, including empty input; disabled calls do not supply. A normal absent/unknown plan is cached; thrown supply retries. Select only a V1_0 plan. Find the **first** annotation named exactly `io.qameta.allure.AllureId` or `io.qameta.allure.kotlin.AllureId`; use its `value` only if a String (no number coercion, array unboxing or search for a later usable ID). Name is `toTestName('.', '.')`, not `#`. For a supported plan, filter/filterNot preserve order and duplicates. **C7:** disabled, absent or unsupported plan means filter returns input but filterNot returns **empty**, including disabled Allure inside a composition.
- **Allure dependency adapter** (2.29.0 JAR, `FileTestPlanSupplier.{supply,tryGetPath,readTestPlan}`, `TestPlan`, `TestPlanV1_0.isSelected`): inspection of the pinned bytecode shows `ALLURE_TESTPLAN_PATH` then `AS_TESTPLAN_PATH`, first non-null/non-empty string **before** path validation, no trim and no fallback after the chosen path fails. Require an existing regular file; relative paths use process cwd. Invalid-path warnings and read/JSON IOException warnings retain the supplier logger/messages; missing/non-regular files yield absence. Mapper ignores unknown properties; `version` dispatches to V1_0 or Unknown. Selection flattens both non-null `id` and `selector` strings from all plan tests and compares **each to either** the candidate name or ID (including cross-field matches and empty strings), not only id-to-id and selector-to-name. Confirm version spelling, null/missing `tests`, null entries, coercion, root-null and exception boundaries with the pinned oracle before freezing the adapter; Kotlin line references above cover its wrapper, not this dependency's implementation.

## Proposed simplifications (for orchestrator approval, not decided)

The user's pragmatic-parity direction is few users, avoid emulating exotic-only quirks. Until approved, source behaviour above stands; record decisions and any changed evidence in findings/deviations, never silently relax a test.

- **P1, unused runtime equality:** omit runtime filter Eq/Hash and unused toString, as approved for strategies in 3.2, after auditing callers. Tests and production use selection, not filter identity/equality. Keep config equality under 2.2 S1 and ordered Test equality for composition; do not reproduce concatenated-pattern equality, enabled omission, or inconsistent hashes merely to expose an unused API.
- **P2, exotic Allure JSON binding:** support ordinary versioned JSON objects with string/null IDs/selectors, ignore unknown properties and retain missing/unknown-plan C7 behaviour, but treat scalar coercions, malformed/null test collections/entries and root-null as a read warning plus absent plan rather than emulating Jackson coercion and later NPEs. This changes only malformed/exotic plans; probe first to enumerate exact changed cases. Missing path, precedence and valid empty plans remain exact. This is not automatically covered by D9, which governs configuration profiles.
- **P3, test-only custom objects:** port `AnnotationDataFilterTest.shouldNotFailWithArrayAnotherType` using an injected test-only element renderer for its custom `AnnotationValue` identity text, rather than adding generic Object to the frozen model. Keep the assertion and snake_case name, plus real typed producer coverage. Reviewer must agree the adapter preserves the test's meaning; no production metadata kind or identity-string parsing is added.
