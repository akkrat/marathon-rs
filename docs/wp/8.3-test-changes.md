# WP 8.3 test changes

Original oracle tables, copied resources and every file under `fixtures/contract/` remain unchanged.
Path changes use `PathBuf` for owned values and `&Path` for borrowed values. Existing test outcomes are unchanged except where D56/D57 apply; unit-only malformed inputs in the deleted path APIs now cross the already-approved D55 replacement boundary before the `&str` API.

D56 is confirmed against the unchanged file manager at `f18ebdd8`: a filename cut inside `a😀z` returns a path whose native conversion fails with `InvalidInput`; the corresponding folder cut fails in materialization. `FileLogWriter` propagates the former, while `ResultBundleRunListener::deliver` logs undelivered output and returns false for the latter. The new regression writes and reads both shortened files and creates the shortened folder.

D57 native expectations are separate fixtures: `fixtures/phase8/d57-yaml.json` covers `UTF8-surrogate`, `UTF8-short-surrogate`, `UTF8-encoded-low-surrogate`, `R2-bytes-138`, and `R2-bytes-143`; `d57-dex-bytes.json` covers 140 of the 11,420 byte-table inputs; `d57-dex-probes.json` changes exact values in `probe.apk`, `probe-utf8.apk`, and `probe-deflated-descriptor.apk`. Each APK override asserts its original value. The analytics Unicode-auth replay changes only the Authorization value to the fixed base64 of UTF-8 `u é😀:päss`. Form/query expectations retain their bytes. The native socket test replaces the deleted Java-format unit test; Android host text used in IDs/results is unchanged.

The tables list directly edited test bodies and the shared test helpers that changed. Import-only edits do not change a test body. Existing test names stay except for the D57 socket helper and supplementary-decoding test whose former names described the removed behavior.
