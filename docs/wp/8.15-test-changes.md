scheduling/cancellation operations. Existing edits only replace deleted trait

unchanged. Paths below are relative to the repository.

## New ownership tests

`crates/marathon-core/src/runtime.rs`, `JobRef` rustdoc, has two
`compile_fail,E0277` tests:

- Capture a job from one run in another `CoreExecutor::run` factory and try to
  attach it as the other executor's parent. Its `Rc<RuntimeJob>` is not Send.
- Return a job from `CoreExecutor::run`. The run's Send result bound rejects it.

Together with private executor/job construction, these pin the ownership
boundary without a registry or a replacement panic. Existing runtime witnesses
still exercise normal construction, spawning, joins, completion callbacks,
observed-child traversal and scoped timeout cleanup.
