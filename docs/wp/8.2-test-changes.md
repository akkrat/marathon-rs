# WP 8.2 test changes

This inventory is relative to `0.12.0-rc.1`. It lists every directly edited Rust test function,
including signatures, construction, and assertions; files whose changes only affect shared imports,
types, fixtures, or helpers are also listed. A shared helper change applies to its existing callers.
No test or copied fixture was removed. Tests outside the D55 cases below retain their expected
behavior; their changes replace wrapper construction, tuple-field access, encoding calls, and
borrowed argument types with native strings, plus the corresponding compiler/Clippy simplifications.

## Added regression coverage

- `jstring::take_counts_utf16_and_preserves_split_pair_filename_bytes`: UTF-16 limits, whole and split pairs, input U+FFFD, and generated path diagnostic bytes.
- `jackson::native_string_tests::json_normalization_preserves_pairs_literals_and_error_positions`: pairs, lone values/keys, escaped backslashes/quotes, invalid syntax, and stable widths.
- `report_text::supplementary_history_ids_keep_the_exact_utf8_digest`: fixed UTF-8 Allure digests for supplementary and replacement text.
- `plist::native_strings::tests::binary_strings_decode_lossily_without_touching_pairs_or_data`: binary strings, valid pairs, and opaque data isolation.
- `plist::native_strings::tests::extended_strings_and_invalid_tables_are_bounded`: extended string lengths, the existing compressed-length marker interpretation, and malformed-layout handling.
- `plist::reader::native_string_tests::xml_encodings_and_numeric_escapes_decode_lossily`: both endian encodings, lone numeric escapes, and paired numeric escapes.
