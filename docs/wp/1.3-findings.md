The configuration, iOS static/dynamic devices, macOS devices and Android profiling call sites listed in the brief all use default settings. No speculative custom delimiters or configurable substitution flags are exposed.

`StringSubstitutor::new(lookup).replace(input)` accepts an injected `Fn(&str) -> Option<String>` and returns `Result<String, SubstitutionError>`. Undefined values remain literal unless a default exists; empty values suppress defaults. Cycles preserve the exact `java.lang.IllegalStateException` class and message. Callers retain the distinction between substitution errors and YAML/configuration wrappers.

The port preserves commons-text's first-suffix matching, disabled substitution in names, recursive substitution restricted to inserted values, escape deletion only for complete expressions, and lazy capture of the original text in cycle messages. Supplementary probes cover nested prefixes inside escaped expressions and delimiters formed across replacement boundaries. These are library semantics, not newly discovered Kotlin bugs.
