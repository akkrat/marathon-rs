## Decisions and consumer API

All final orchestrator decisions in `5.1.md` were applied. S1–S5 are retained:
fixture quirks below, sorted UDID inventory, a documented vendor-thread-only
blocking connection hook, direct virtual file transfers and argv-only recording.
The approved `4.5b -> 5.1` dependency was already present on the base; PLAN needs
no further change. There are **zero 5.1 parity rows and zero inventory rows**.
No CSV changed, no row was ported or marked n/a, and no resource was copied.

Both executors live in `marathon-test-support::apple`, with no iOS dependency.
`FakeSimulatorWorker::new(runtime, logging)` defaults to the Kotlin profile;
`with_host_id`, `with_simulators`, public `home`, locked `arch` and
`xcodebuild_version`, `add`/`add_with`, and each Simulator's atomic `available`
cover consumer setup. The simulator map and values are Arc-shared. Hooks are
Arc closures in short Mutex slots, cloned before invoking or awaiting them:
`BeforeHook(Vec<String>) -> VendorFuture<Option<CommandResult>>`,
`SessionHook(&[String]) -> VendorResult<Option<CommandSession>>`, and
`ConnectedHook()`. Session hooks can return the existing CommandSession with
custom blocking-close control. Blocking connection hooks must run on a vendor
worker thread; the contract test uses a bounded blocking-pool rendezvous.
The command recorder and the counters remain independent of connection state.
Failure constructors cover ConnectionException, TransportException, IOException
and CancellationException; typed cancellation remains VendorError::Cancelled.

`WorldExecutor::new` takes a Router, VirtualFs, fixture directory and runtime;
put a cloned World in Router.extensions. `new_connection` shares world/files/
PIDs and gives a separate connection lifetime. Independent construction creates
independent backends. `before` injects transport-class failures, result overrides
or state changes. The world keeps measured Xcode 27.1, separate from the fake's
Xcode 16.4 / iOS 18.6. No new effect DSL or Apple implementation was introduced.

## Changes to merged crates

* **marathon-apple:** feature-gated public `CommandSession::finished(runtime,
  result)` replaces its crate-private with_result builder. FakeCommandExecutor
  delegates to it. Production executor behavior is unchanged.
* **marathon-ios:** dev-dependency on marathon-test-support only.
* **marathon-test-support:** the two executors, WorldFileBridge, hooks, counters,
  Failure constructors and contract tests; normal dependencies on marathon-apple
  with test-support and fake-worker. No product crate gains fake-worker as a
  normal dependency.
* **fake-worker:** shared transport-independent Execution/Sink, VirtualFs local
  import/export, and per-initial-UDID destinations, preferences, recording cleanup
  and capture barriers. SSH retains its existing finish/EOF/CLOSE operations,
  transport faults, transcript and real rsync adapter. Foreground Publish adds
  startup and selected-signal publication for live recording sessions.

Foreground tasks are spawned on the supplied VendorRuntime and tracked through
connection close. Session drop cancels its plan; explicit close joins it. Nohup
and device-log jobs retain the connection lifetime and existing process registry;
SignalPid joins and publishes using the same runner on both transports. Direct
file imports/exports preserve bytes, Unix modes and tree links through the
contained VirtualFs blocking pool. A raw rsync fails with an explicit error.
