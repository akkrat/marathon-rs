## Implementation and boundary

`device::simulator_provider::AppleSimulatorProvider` implements the frozen core
provider contract. Public initialize/update/borrow work is dispatched through the
injected vendor runtime; blocking file binding uses its blocking pool. One shared
consuming event queue preserves buffered close. Source tasks, update tasks,
notification tasks and protected termination are retained and joined explicitly.
The provider does not close the shared run runtime. Initialization is rejected
on direct reuse (approved P2); termination is idempotent, including before init.

Static existence takes precedence over dynamic configuration, including a directory
at the file path. P2 is enforced without another post-processing pass. Only
Jackson databind errors get the NoDevices wrapper; substitution, null, I/O and
stream boundaries remain separate. Existing binding classes/causes are retained;
see U83 below for shared binder diagnostics that do not match the JVM text.

Dynamic TCP owns its socket, closes it on cancellation and joins the producer.
Exactly one frame is decoded before each rendezvous handoff: a one-slot channel
plus receive acknowledgement prevents decoding the successor before its source
send can complete. At most one snapshot is received per 16 ms monitoring cycle.
Refused connections delay 5000 ms; other failures permanently end only the
producer (A1). A closed source is never restarted. The merged decoder performs
all payload decoding, substitution, binding and approved length validation.

Snapshots are serialized, with one tracker mutation before worker I/O. Worker
failures are isolated; cancellation signals sibling setups and joins their cleanup.
Disposal and additions run concurrently and are all awaited
before the next snapshot. Removal markers and registration share a lock. Dead
executors notify disconnect and leave disposal to recovery. Registry entries are
retained after removal, so stale borrow and the retained-entry DEBUG count match
Kotlin. Borrow uses the stable `ios.AppleSimulatorProvider.borrow` key and 200 ms
empty-map delay; no host-RNG fallback is supplied on hook failure.

Planning passes fresh registered/current callbacks to merged PlanCalculator.
Disposed allocations are eligible only while connected, current, present and
outside recovering/exhausted/retired state. One context covers inventory, planning
and every setup of a worker cycle. Planning references are released independently
in a finally boundary; failed plans do not cancel healthy workers. Failed setup
results map back to explicit targets or reused profiles for the retry handoff.
Timing uses the merged wall-Timer helper with wrapping subtraction and separate
suffix reads. The provider keeps its simple logger name; the extracted planner
keeps its existing qualified name. Kotlin data-class target/update rendering uses
jcompat, and replacement object suffixes use per-allocation ReplayHooks identities.

Registration publishes the same concrete Arc/DeviceRef allocation atomically,
then awaits predecessor disposal before launching Connected. Replaced references
are kept until after the artifact barrier, except when recovery owns retention.
Termination cancels/joins monitoring and updates, awaits the injected retry root,
closes events, awaits the real artifact processor's existing 300000/60000 ms
budgets, then disposes/releases devices concurrently and replaced references
sequentially. Disposal failure skips release (A82). No unbounded artifact join is
added. Failed async notification sends retain a typed task error and report the
original throwable independently of the registering caller, without a new custom
message or JVM thread/frame preamble.

`ios_vendor::IosVendor` constructs explicit VendorServices: the provider, selected
remote XCTest/nm parser (configuration defaults to nm), Apple log configurator,
and one shared identifier. Device construction shares the run's artifact queue,
transfers, track, timer, output and injected listener factory. Construction runs
no provider initialization. The CLI unsupported gate is unchanged.
