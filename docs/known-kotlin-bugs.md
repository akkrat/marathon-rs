# Known bugs in the Kotlin marathon (e47352f2) that v1 keeps

Decision D5 (2026-10-12): the Rust v1 reproduces these, so it can be compared with Kotlin directly. Each one is a candidate fix after cutover.

**How to maintain this list**
- Implementers and reviewers add an entry whenever they find a bug that the port has to preserve.
- Each entry names its Kotlin location, the behaviour, and where the Rust port reproduces it (WP).
- The entries below were seeded from the Phase 0 source surveys. Each one is confirmed, or corrected, when its WP ports the code.

Status values: `seeded` (from the surveys, not yet confirmed), `confirmed` (reproduced by a Rust test), `fixed-after-cutover`.
